# v4.3 相似节点软伪样本排序

本目录整理 v4.3 实验版本。该版本在原 v4.1 Pairwise 利润排序基础上，将高相似节点的未观测“节点-业务”组合作为软伪样本加入训练，用于改善未见业务的排序泛化。

## 最佳配置

- 节点余弦相似度阈值：`0.995`
- 伪样本权重：`1.0`
- 近邻数：`3`
- 伪样本数：`6,612`
- 覆盖伪样本节点：`2,629`
- 排序训练行数：`13,412`
- 验证集严格与训练集、伪标签来源隔离

虽然参数名为伪样本权重，但 XGBoost Ranker 的 `sample_weight` 是查询组权重，不是逐行权重。脚本按节点聚合真实样本与伪样本权重后传入模型。当前最佳值为 `1.0`。

## 验证结果

| 版本 | Pairwise Accuracy | NDCG@3 | 平均 Top1 机会损失 |
|---|---:|---:|---:|
| v4.1 基线 | 64.78% | 0.8700 | 6.3507 |
| v4.3，阈值 0.995、权重 1.0 | **65.54%** | **0.8728** | **6.3435** |

## 未来测试集

测试窗口为 `2026-08-28` 至 `2026-09-03`。

| 范围 | 节点数 | Pairwise | Top1 | NDCG@3 | 平均 Top1 机会损失 |
|---|---:|---:|---:|---:|---:|
| 全部多业务节点 | 1,556 | 75.24% | 83.68% | 0.9443 | 16.4686 |
| 含未见业务的混合节点 | 235 | 67.48% | 62.98% | 0.8734 | 38.2839 |
| 纯未见业务 | 92 | **67.46%** | **71.74%** | **0.9028** | 15.1264 |

纯未见业务相对 v4.2 的 Pairwise 从 `62.72%` 提升到 `67.46%`，Top1 从 `67.39%` 提升到 `71.74%`，NDCG@3 从 `0.8849` 提升到 `0.9028`。但全部多业务节点指标低于 v4.2，且纯未见业务平均机会损失由 `13.8271` 增至 `15.1264`。

因此 v4.3 暂不全面替代 v4.2。推荐策略是已见业务继续使用 v4.2，纯未见业务使用 v4.3，并保留金额风险约束。

## 复现实验

训练脚本依赖项目研究环境中的数据构建与公共特征模块，不能只依靠本目录内的脱敏结果重新训练。具备完整研究数据后，在项目根目录运行：

```powershell
python train_v43_soft_pseudo_samples.py --weight 1.0 --threshold 0.995
```

内网原始训练数据、凭据和鉴权信息不包含在仓库中。
