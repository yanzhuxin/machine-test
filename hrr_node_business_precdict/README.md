# hrr_node_business_precdict

HRR 的节点—业务反事实金额预测与存量节点业务推荐项目。仓库按迭代阶段拆分，便于区分金额预测、相似节点验证与当前利润排序版本。

## 版本演进

| 版本 | 目录 | 目标 | 当前定位 |
|---|---|---|---|
| 01 | `01_counterfactual_amount_prediction/` | 预测节点运行目标业务的 7 天成本、收入与利润 | 当前正式金额预测基线 |
| 02 | `02_similar_node_aggregation/` | 按节点固有特征找近邻，验证相同业务金额是否更接近 | 在 01 基础上的业务扩散预验证 |
| 04 | `04_profit_recommendation_v4/` | 对存量节点的可行业务进行金额预测、去偏利润排序，并用高相似节点软伪样本增强未见业务泛化 | v4.1 生产基线与 v4.3 未见业务候选 |

流程关系：

```text
01：节点特征 + 业务 + 历史金额
    → 业务先验 / 矩阵分解 / XGBoost / 受约束融合
    → 成本、收入预测

02：节点固有特征
    → 特征近邻图
    → 共同业务金额差异验证
    → 近邻遮挡预测
    → 判断是否值得把近邻信号加入 01

04：相似节点成本/收入/利润 XGBoost + Pairwise Ranker
    → 汇聚/专线业务准入过滤
    → 金额路线 Top3 + 去偏利润路线 Top3
    → 合并 Top5、Top1 审核、高确定性切换与互换候选
```

02 没有替换 01，而是为相似节点信号提供预验证。04 已把相似节点信号接入金额与利润模型，并增加节点内部业务相对排序优化。

## 主要结果

| 模型 | 成本 WAPE | 成本 R² | 收入 WAPE | 收入 R² |
|---|---:|---:|---:|---:|
| 01 历史增强融合模型 | 56.88% | 0.6399 | 61.12% | 0.5321 |
| 02 最优纯近邻模型 | 61.33% | 0.6462 | 65.64% | 0.5520 |

01 的验证设计为节点内部 90% 训练、10% 业务遮挡，共 8,673 条完整 7 天记录，其中训练 7,806 条、验证 867 条。

04 的 v4.1 节点内排序验证结果为 Pairwise Accuracy 0.6478、NDCG@3 0.8700、平均 Top1 后悔值 6.3507；v4.3 以相似度阈值 0.995 和伪样本权重 1.0 将验证指标提升至 0.6554、0.8728 和 6.3435。未来纯未见业务测试中，v4.3 Pairwise 为 0.6746、Top1 为 0.7174、NDCG@3 为 0.9028；当前建议 v4.2 服务已见业务，v4.3 服务纯未见业务。
