# 02 相似节点聚合与业务扩散预验证

第二版扩展实验：只使用节点固有特征寻找相似节点，再检查相似节点运行相同业务时，成本和收入是否比随机节点更接近。

## 与 01 的关系

本版本依赖 `../01_counterfactual_amount_prediction/` 中的节点数据、90/10 遮挡逻辑和当前融合模型预测。金额和已运行业务不会参与节点相似度计算。

## 相似度方法

- 45 个节点类别特征：One-Hot、缺失类别、分块归一化，权重 65%。
- 17 个静态容量特征：中位数填充、缺失指示、分位数变换，权重 35%。
- 使用余弦距离为每个节点寻找 Top-10 近邻。
- 将同业务相似节点金额差与随机同业务节点比较。
- 再对 867 条 10% 遮挡记录执行 KNN 加权均值/中位数预测。

## 当前结果

- Top-10 去重相似节点对：35,611。
- 至少有一个共同完整业务的节点对：12,810，占 35.97%。
- 相似节点成本平均 sMAPE：88.70%；随机对照：103.09%。
- 相似节点收入平均 sMAPE：92.16%；随机对照：105.73%。
- 最优纯近邻成本 WAPE：61.33%。
- 最优纯近邻收入 WAPE：65.64%。

结论：相似节点信号有统计价值，但目前适合作为 01 的补充特征，不适合直接替代 01。
